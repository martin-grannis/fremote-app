What it does

📱

Freeshow remote control

Great for service or worship leaders when no tech operator available>

🗂️

Project & show browser

Browse your FreeShow service plans and use NEXT to step through or go direct to any slide.

🎵

Audio & video tiles

Version 2 also plays audio and video slides.

⬛

Auto blank

Clears the screen between items to avoid stepping into an item early.

Installation

1

Download the APK

Tap the Download button above on your Android device, or transfer the file to it.

2

Allow installs from unknown sources

Android will ask you to allow installation from this source the first time. Tap Settings → Allow, then come back and tap Install.

3

Enable the FreeShow Remote API

Freeshow server remote must be enabled (as you would do for the official remote app)

4

Connect

Open FRemote, enter your PC's IP address, port, and password (if set), then tap Connect.

Same Wi-Fi network required. Your Android device and the PC running FreeShow must be on the same local network.
